# JustHUD

**JustHUD — by Just Studio**

JustHUD is a Minecraft HUD modification designed to provide useful in-game information through a clean, modern and minimalistic interface.

Developed by **Just Studio**, JustHUD combines several useful HUD elements into one convenient display, helping players keep track of important game information without unnecessary clutter.

---

## ✨ Features

- **FPS Counter** — Displays your current frames per second.
- **CPS Counter** — Tracks your clicks per second.
- **Coordinates** — Shows your current X, Y and Z coordinates.
- **Armor Durability** — Displays the durability of your equipped armor.
- **Entity Information** — Provides useful information about entities.
- **Keystrokes** — Displays your keyboard inputs in real time.

## 📦 Installation

1. Install **Minecraft Forge**.
2. Download the latest `JustHUD.jar` file from [Releases](../../releases/latest).
3. Open your Minecraft game directory.
4. Place the `.jar` file into the `mods` folder.
5. Launch Minecraft using the Forge profile.

That's it! JustHUD is ready to use.

---

## ⚙️ Configuration

JustHUD uses an external configuration file located in your Minecraft game directory.

You can customize supported HUD settings by manually editing the configuration file.

> **Note:** There is currently no in-game HUD customization menu.
